# Master Architectural Design Document: Paper-First Multi-Agent Trading System

**Mantra:** Nothing is impossible — but physics, broker APIs, and risk still apply.

**Status:** P0–P2 implemented in package `pa`. Live trading is structurally blocked. Vendor keys are optional (fixtures if absent).

---

## 1. Purpose and non-goals

### Purpose

A continuous, operator-supervised paper-trading system for liquid US ETFs and their listed options. Specialized modules (called agents) share typed messages on an in-process bus. A Master Orchestrator sequences **data → signal → risk → paper fill → journal**. The first live loop is a 1-minute decision cadence, not high-frequency trading.

Default universe: `SPY`, `QQQ`.

Default strategy (P0): enter when 1m / 5m / 15m EMA alignment, VWAP side, and non-extreme RSI agree. Prefer a liquid weekly ATM call/put when an options snapshot exists; otherwise paper-trade the ETF.

### Non-goals (this system will not)

- Sub-millisecond or exchange-colocated execution.
- Unofficial Robinhood APIs, window scraping, or mouse/keyboard UI automation.
- Treating Yahoo Finance or Finviz as Level 2, dark-pool, or unusual-flow sources.
- Self-applying code patches generated by an LLM while the process can trade.
- Voice-triggered orders, mobile remote execution, or multi-account mirroring.
- Live broker orders until paper results, replay, and risk gates are proven.

### Latency budget (honest)

| Hop | Target | Notes |
|-----|--------|-------|
| In-process bus | < 1 ms | Same Python process, asyncio queues |
| Polygon REST poll | 50–500 ms | Network + plan limits; not a websocket HFT feed in P0 |
| Decision on 1m bar close | 100 ms–2 s | Indicator + risk + journal |
| Paper fill | Immediate (simulated) | Models spread and slippage; does not hit an exchange |

## 3. Domain contracts

All agents speak these pydantic models (see `src/pa/domain/models.py`). No ad-hoc dicts on the bus.

| Contract | Role |
|----------|------|
| `Bar` | OHLCV + ticker + timeframe + ET timestamp |
| `Quote` | Bid/ask/mid/last + size |
| `OptionSnapshot` | OCC symbol, expiry, strike, right, greeks, IV, quote |
| `Signal` | Ticker, side (`buy`/`sell`/`flat`), confidence 0–1, reasons[], source agent, ts |
| `OrderIntent` | Client order id, ticker, qty, side, asset class, `trading_mode="paper"`, optional OCC symbol, limit hint |
| `RiskDecision` | `allow` / `deny` / `halt`, reasons[], sized qty |
| `Fill` | Intent id, price, qty, slippage, ts |
| `Position` | Ticker, qty, avg price, unrealized/realized, asset class |
| `KillSwitchEvent` | Source (`file` / `api` / `drawdown` / `operator`), ts, message |
| `JournalEvent` | Envelope: topic, payload JSON, ts |

Conflict resolution (P0): a single quant strategy emits one `Signal` per ticker per bar. When multiple signals exist later, the orchestrator picks the highest confidence **only if** risk allows; weights are observational, not auto-scaled by recent P&L.

## 4. Safety model

Live money is not a config flag you flip casually.

1. **Paper lock.** `TRADING_MODE` must be `paper`. Any other value raises at settings load. `OrderIntent.trading_mode` is always `paper`. No live broker module is imported.
2. **Kill switch.** Presence of the kill file (`data/KILL` by default) or `POST /kill` halts new entries and instructs the paper broker to flatten. Survives process restart until the file is removed.
3. **Daily drawdown halt.** If session P&L ≤ −`daily_drawdown_pct` of starting equity, halt for the rest of the session (flatten, no new risk).
4. **Position and notional caps.** `max_open_positions`, `max_risk_per_trade_pct` of equity. Risk **reduces qty** or **denies**; it never increases size.
5. **Session filters.** No entries before the open buffer, during the lunch window, after the close buffer, or outside RTH. Process stays up and serves the API; the loop logs `skip: session_closed` (or the specific buffer).
6. **Earnings blackout (stub).** Interface exists; P0 uses an empty set unless `EARNINGS_BLACKOUT` tickers are configured.
7. **0DTE.** P0 does not buy 0DTE. Weekly (or later) expiries only.
8. **Idempotent orders.** Every intent has a client order id. Replays do not double-fill the same id.
9. **No self-modifying trading code.** Failures journal a patch *request* at most (P2). Humans apply code.

```
Polygon / fixtures → Quant → Orchestrator → Risk → PaperBroker → SQLite journal
                                         ↘ kill/halt ↗ flatten
```

## 5. Runtime topology (P0)

Single process:

1. Market clock (America/New_York, NYSE holidays + early closes).
2. Data adapter (Polygon, or deterministic fixtures if `POLYGON_API_KEY` is missing).
3. Quant indicators + MTF strategy.
4. Orchestrator (cadence, skip reasons, journal).
5. Risk gates + kill switch.
6. Paper broker (spread/slippage fill model).
7. FastAPI in the same event loop.

Outside RTH the loop does not place orders. Health endpoints remain live (24/7 process, not 24/7 trading).

## 7. Roadmap

### P0 — Foundation (done)

Package `pa`: config + paper lock, ET clock, Polygon/fixture data, VWAP/EMA/RSI/MACD/MTF strategy, risk gates, paper broker, orchestrator loop, SQLite journal, FastAPI status/kill, pytest.

### P1 — Prove the loop (done)

Bar replay, richer dashboard, VIX overlay (halt + size-down), RSI divergence, trailing stops / scale-out, observational agent scores, economic calendar, earnings dates, TradingView `Signal` ingest (risk still mandatory), GitHub Actions, Docker, outbound webhook, journal prune.

### P2 — Research and operator luxuries (done as modules)

News/NLP lexicon + optional NewsAPI, silent chat (no microphone), LLM-agnostic consult (OpenAI optional), synthetic L2/flow fixtures, walk-forward report (not auto-applied), `Broker` protocol + internal paper default, wash-sale flag, tax estimate, beta-hedge note, custom indicator spec parser, CPU replay device hook, prompt file hot-reload, patch requests journaled never applied.

**Chart trader (2025 hunt):** `python -m pa.chart_trader` replays hourly SPY with causal indicators only (no look-ahead). Multi-ticker scan: `python -m pa.chart_trader.scan` writes Monday morning option-style cards to the desk (`Buy TSLA 360 Call Exp 8/31 for $1.50` / sell-to-exit / take-profit %). Accuracy is Oct–Dec OOS, not 99%.

**Go-live gate (not a date):** weeks of paper results, replay matching journaled decisions, kill switch drills, and a written broker adapter review. Until then `TRADING_MODE=paper` is the only legal value.
